# 智练 TrainMate 平台图标索引

## 已接入平台

- iOS：替换 AppIcon 目录中的 15 张实际 PNG，保持 `Contents.json` 不变，全部为 RGB 且无 Alpha。
- Android：替换 5 张旧式启动图标，并同步生成 5 张透明 Adaptive Icon 前景、同名自适应 XML 与浅桃背景色资源。
- Web：替换 favicon、192px、512px 及两张 Maskable 图标，保持 `manifest.json` 与 `index.html` 不变。

## 视觉规则

- 保持原品牌色不变：深蓝黑 `#19172C`／`#11101F`、纸白 `#FFFDFC`、桃色 `#FFB27D` 与浅桃 `#FFE2B8`。
- 参考图仅用于圆润轮廓、柔光层次、轻阴影与留白比例，不引入蓝紫新色。
- 纸白软胶囊必须保留。
- 胶囊内为左侧深墨眼点与右侧深墨弯眼。
- 桃色短嘴位于胶囊下方，并与胶囊下缘保持明显间隔。
- 桃色奋斗头带、软结与两条不等长短飘带全部保留。
- 角色整体向右前倾 `5°`，背景保持端正，所有脸部与头带元素同步旋转。
- 平台图标不包含四肢、文字或纹理；只允许使用既有品牌色形成低幅渐变与轻阴影。

## 生成入口

```bash
python3 scripts/generate_brand_assets.py --platform all
```

## 校验入口

```bash
python3 scripts/verify_brand_assets.py --platform ios
python3 scripts/verify_brand_assets.py --platform android
python3 scripts/verify_brand_assets.py --platform web
python3 -m unittest discover -s scripts/tests -p 'test_brand_assets.py'
```
