# TrainMate Flow 20 动作浅蜜桃语义表情资产清单

## 交付边界

- 本目录是现有墨兰版 `action-set-20` 的独立浅蜜桃配色版本。
- 本次按用户确认覆盖本目录 20 张正式动作图、总览及 App 同名缩放副本；墨兰版作为并列配色保留，不修改 Flutter 代码、主题 Token、品牌公共文件或应用图标。
- 单图沿用原文件名，全部为 `1254 × 1254`、1:1、真实透明 PNG。
- 总览图使用纸白背景，按 5 列 × 4 行排列，不添加文字、编号或水印。

## 配色映射

| 区域 | 固定颜色 |
| --- | --- |
| 身体、四肢、手脚 | 高光 `#FFF0D7`、基色 `#FFE2B8`、阴影 `#F5C98E` |
| 细边缘与器械 | 深墨兰 `#11101F`；跳绳与哑铃保持深墨兰 |
| 眼罩 | 纸白 `#FFFDFC` |
| 头带与飘带 | `#FF641C` 到 `#FFB27D` 的橙桃渐变 |
| 眉眼与瞳孔 | 墨兰 `#19172C`，睁眼动作保留纸白高光 |
| 嘴 | 墨兰 `#11101F`；微笑、直线或收紧嘴型按动作语义变化 |
| 情绪符号 | 青绿 `#64D9D0`，仅用于汗滴、灵感线和庆祝点 |

角色继续保持原动作比例、柔和立体明暗与浅蜜桃肢体；睁眼动作使用高光圆眼，放松、冥想与庆祝动作使用闭眼或半闭眼，同编号与墨兰版保持相同表情语义。

## 表情分组

| 语义组 | 动作编号 | 表情规则 |
| --- | --- | --- |
| 引导与觉察 | 01、11 | 视线朝动作方向、觉察眉眼、轻微笑 |
| 快乐与庆祝 | 02、05、08 | 高光眼或笑眼；05 增加橙青庆祝点 |
| 放松与平衡 | 03、04、18、19、20 | 半闭或闭眼、舒缓微笑 |
| 速度与专注 | 06、07、10、14 | 压低眉、聚焦视线；高强度动作允许青绿汗滴 |
| 高强度与坚持 | 09、12、13、15、17 | 收紧嘴型、用力眉、高光眼和指定汗滴 |
| 力量与自信 | 16 | 不对称自信眉、半弧微笑 |
