# 智练 TrainMate App 图标｜动作家族双飘带版 V11

## 设计变化

- 只调整奋斗头带后的双飘带，主体、头带、软结、胶囊脸、双圆点眼、短嘴、配色与版式均保持 V10 不变。
- 将原先偏厚、易被看成叶片的两块尾带，改为参考动作角色家族的轻薄波浪布带。
- 长带向左后方自然拉开，约占主体宽度 `22.0%`；短带约占主体宽度 `17.5%`。
- 两条飘带保持同向、近似平行，只做轻微上下错位；长短比约 `1.26`，各包含一至两次自然弯折。
- 阴影直接复用正式飘带轮廓，仅下移 `8` 个 SVG 单位并降至 `12%` 不透明度，避免重复偏移造成厚重感。

## 小尺寸审阅

- `app-icon-180.png`：iOS 主屏常用三倍图审阅稿，双飘带分离清楚。

- `app-icon-maskable-512.png`：头像与双飘带保持在平台安全圆内。

## 几何校验

- 标准图标墨兰主体占比：`83.20% × 85.84%`，与 V10 相同。
- 标准图标橙金配饰像素边界：`(35, 294)–(931, 739)`，左右均保留超过 `24px` 的安全边距。
- 标准与 Maskable SVG 使用完全相同的两条定稿路径，平台只改变整体安全区缩放。
