# 智练 TrainMate App 图标｜角色头像版 V9

## 设计依据

- 角色基准：`outputs/logos/trainmate-flow/action-set-20/trainmate-flow-action-set-20-overview.png` 第一格正面角色。
- 用户参考图与仓库总览图 SHA-256 一致：`480d905205bb6678ddb0fa5a2dadfa9f3e9cdf6c51a6e8bae3a1054463b3adc4`。
- 采用项目矢量品牌母版重绘，不嵌入动作 PNG，保证平台导出可重复。

## 本轮调整

- 将 V8 贴边雕塑轮廓改为圆润、独立悬浮的墨兰角色头像。
- 表情改为动作角色统一的双圆点眼与桃色短弧微笑。
- 软结和双短飘带移动到左侧，与正面角色头像一致。
- 去除手、脚和运动道具，只保留头像识别元素。
- 奋斗头带、软结和双飘带继续使用橙金渐变 `#EAA93A → #C65F14`。
- 墨兰主体继续使用 `#19172C / #11101F`，胶囊脸使用 `#FFFDFC`，背景使用 `#FFFDFC → #FFE2B8`。

## 比例与安全区

- 普通版墨兰主体占画布约 `79.5% × 81.8%`。
- 普通版橙色配饰边界为 `x=35–931`，双飘带完整保留。
- Maskable 透明前景最大半径占画布 `30.7%`，位于平台直径 `80%` 的安全圆内。
- 16px favicon 使用居中裁切，避免角色向右下偏移。
