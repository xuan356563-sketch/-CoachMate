# 智练 TrainMate App 图标｜樱桃红大主体奋斗版 V4

## 本轮调整

- 保留浅桃柔光背景、深蓝主体、白色胶囊脸、桃色嘴与樱桃红奋斗配饰，颜色不再改变。
- 主体、胶囊脸和阴影由 `93%` 放大至 `108%`，普通版深蓝主体实测约占画布 `67.4% × 69.6%`。
- 奋斗头带纵向放大至 `144%`，与主体同步增强。
- 软结整体放大至 `158%`。
- 长飘带调整为 `-10°`、横向 `158%`、纵向 `124%`。
- 短飘带调整为 `+12°`、横向 `150%`、纵向 `124%`。
- 普通版完整角色约占画布 `79.4% × 71.9%`，接近参考图的大主体满幅感。

## 约束

- 樱桃红只用于 App 图标的奋斗头带、软结和双短飘带，不扩散到正式 Logo 家族。
- 桃色嘴固定使用 `#FFB27D`，不跟随头带渐变变色。
- 普通版与 Maskable 版使用同一套角色比例；Maskable 深蓝主体实测约占画布 `48.4% × 50.2%`，仍位于平台安全区。
- 主体、头带、软结和双飘带均保持为 `flow-avatar` 的直属节点，避免嵌套缩放造成比例漂移。
