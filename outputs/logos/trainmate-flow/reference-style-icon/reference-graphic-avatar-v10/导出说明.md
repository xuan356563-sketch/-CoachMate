# 智练 TrainMate App 图标｜参考图形主体版 V10

## 设计变化

- 仅重塑墨兰主体轮廓：改为左重右轻的连续有机冠形与圆钝软盾牌底部。
- 借鉴参考图的粗轮廓、非对称块面和强负形，不复制熊猫、骰子或动物耳朵造型。
- 删除旧主体的大投影与白色高光弧，提升 60px 和 16px 下的平面识别度。
- 保留橙金奋斗头带、放大软结、两条不等长短飘带、白色胶囊脸、双圆点眼和桃色短嘴。
- 保留原品牌色、图标背景、平台配置、包名与 Flutter 业务代码。

## 几何校验

- 标准图标墨兰主体占比：`83.20% × 85.84%`。
- Maskable 前景最大半径占画布：`32.10%`，满足直径 80% 安全圆约束。
- 主体保持单一连续路径，避免拆分后在小尺寸下形成耳朵或碎片误读。
