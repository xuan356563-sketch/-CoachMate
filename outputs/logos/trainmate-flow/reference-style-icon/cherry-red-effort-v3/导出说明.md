# 智练 TrainMate App 图标｜樱桃红奋斗强调版 V3

## 本轮调整

- 保留浅桃柔光背景、深蓝主体、白色胶囊脸和桃色嘴。
- 奋斗头带、软结、长飘带和短飘带统一改为樱桃红渐变：`#E43D52 → #B5122F`。
- 主体、脸和阴影缩放至 `93%`，为头带和双飘带让出视觉空间。
- 头带纵向放大至 `138%`。
- 软结整体放大至 `150%`。
- 长飘带调整为 `-9°`、横向 `150%`、纵向 `120%`。
- 短飘带调整为 `+11°`、横向 `142%`、纵向 `120%`。

## 文件

- `app-icon-1024.png`：App Store 与设计审阅主图。
- `app-icon-60.png`：小尺寸识别性检查图。
- `simulator-home-screen.jpg`：iOS Simulator 实机安装核对图。

## 约束

- 樱桃红仅允许出现在 App 图标的奋斗头带渐变端点中，不扩散到正式 Logo 家族。
- 桃色嘴固定使用 `#FFB27D`，不跟随头带渐变变色。
- 普通版与 Maskable 版共用同一套角色比例，Maskable 版保留更宽安全区。
