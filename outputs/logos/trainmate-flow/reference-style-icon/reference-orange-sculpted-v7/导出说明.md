# 智练 TrainMate App 图标｜参考橙雕塑构图版 V7

## 本轮调整

- 奋斗头带、软结与双短飘带统一使用参考图的橙金渐变：`#EAA93A → #C65F14`。
- 深蓝主体、浅桃背景、白色胶囊脸与桃色嘴保持既有品牌色，不随配饰变色。
- 头带采用宽弧形构图，软结使用多瓣有机轮廓；两条飘带均为独立、渐细的闭合曲面。
- 主体采用左侧与底部贴边、右侧保留浅桃负空间的构图，避免旧版简单放大裁切的拥挤感。
- 胶囊脸只保留轻微 `2.5°` 角度，确保小尺寸下表情清晰。

## 文件

- `app-icon-concept.svg`：本版本审阅母版。
- `app-icon-1024.png`：App Store 与设计审阅主图。
- `app-icon-180.png`：iOS 主屏尺寸审阅图。
- `app-icon-60.png`：小尺寸辨识度检查图。
- `simulator-home-screen.jpg`：iOS Simulator 安装核对图，完成安装后生成。

## 正式接入

- 普通母版：`assets/branding/source/trainmate-flow-app-icon.svg`
- Maskable 母版：`assets/branding/source/trainmate-flow-app-icon-maskable.svg`
- 平台资源由 `scripts/generate_brand_assets.py --platform all` 确定性导出。
- Maskable 版使用独立安全区布局，防止自适应蒙版裁掉头带与双飘带。

## 版本保护

- 上一版樱桃红方案保留在 `cherry-red-sculpted-v6`，未被覆盖。
- 本目录仅承载参考橙 V7，便于后续并排审阅和回退。
