1. 44px 下能否识别陶土红头带、琥珀双眼和爱心舌头。
2. 右上绑带是否明确包含打结和两条短飘带，并与横向头带自然连接。
3. 是否第一眼明确读成牛皮纸袋：折叠平顶、侧褶、纸纤维、皱折和不规则撕裂眼槽都应清楚，不能像饭盒或硬质设备。

6. 是否出现文字、乱码、翅膀、身体、手脚或其他未要求元素。
7. 面板是否与正式 Logo 属于同一品牌，同时比完整徽章更适合小尺寸界面。
8. 完整人物是否恢复陶土色圆胖身体、双拳、灰白流苏围巾、双腿和米色训练鞋，且从纸袋顶到鞋底完整入画。
