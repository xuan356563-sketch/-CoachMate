# Cron Prompt Template v1（信息摄入类）

> **本文件用途**: 新建"信息摄入 + 加工 + 推送"类 cron 时的起点模板。
> **方法论来源**: `~/self-improving/domains/information-curation.md`（last30days 启发 8 条）
> **实战参考**: 已落地的两个 cron
> - 8:00 AI 视频创意日报（垂直深度版）
> - 8:30 AI 行业速报（横向广度版）

---

## 📋 模板结构（按顺序）

```markdown
# 任务名：{cron 名}（阿轩专属 · {HH:MM} 版）

## 🎯 服务对象
- 谁：{一句话描述阿轩身份 + 这个 cron 服务的子领域}
- 与其他 cron 的关系：{横向/纵向/独立}
- ⏰ 时间窗口：过去 24 小时

## 🔍 搜索维度（M1 互动信号）
- 30% 互动信号源：{X/Reddit/HN/YouTube/B站 等}
- 70% 权威媒体：{36氪/量子位/TechCrunch 等}
- 关键词策略：每领域 2 套关键词（中文权威 + 英文讨论）

## 📌 采集范围（按权重）
1. 【权重 X%】{领域 1} —— 覆盖 {信源列表}
2. 【权重 Y%】{领域 2}
3. ...
N. 【权重 Z%】{边缘动态}

## ❌ 不收录（噪音过滤）
- {显式列出会被拒的"看似相关实则没用"的内容}

## 📤 输出格式（v2 升级版）

### 推送首行 = 身份锚 + 扫描状态（M4）
```
# {emoji} {cron 名} | M月D日（周X） | 已扫 N 平台 · 候选 X 条 · 入选 Y 条
```
- 严格：第一行不可加任何其他内容
- 三项数字 N/X/Y 必填，真实

### 主内容（{N} 条，按重要性降序）
```
## {emoji} TOP N ｜ [分类标签]
**标题**：[一句话标题，30字内]
**摘要**：[150-200字]
**来源**：[媒体名] + [URL]
```

### 推送末尾 = 扫描状态条（M7）
```
---
📊 本次扫描：{实际搜索源 + 关键词数}
⚠️ 今日状态：[正常/行业平静/重大事件日] — 实际入选 [N] 条（平时 X-Y 条）
```

## 🧠 独立思考（{N} 字，四维度）
1. 技术可行性
2. 市场影响
3. 应用市场
4. 挑战
末尾：**阿轩视角 takeaway**（具体到工具/工作流/项目）

## 🚫 AI 套话禁词清单（M3 硬规则）
- ❌ 重磅、炸裂、家人们、绝绝子、划重点、一文读懂、深度好文
- ❌ `—`/`–` → 用 ` - `
- ❌ `## ` / `### ` 段头（除已定义的）
- ❌ 空话开头："人工智能时代已经到来"
- ❌ 无数字/无来源的"感觉性"判断

## 📚 输出样本参考（M6）
### ✅ 好样本
> {具体到本 cron 领域的好例子}

### ❌ 差样本
> {具体到本 cron 领域的差例子}

## 🛡 质量硬约束
- 每条 150-200 字
- 重要性降序（不是时间序）
- 国内外平衡（如适用）
- 信息可验证

## 🚨 内容策略红线
- 不讨论政治人物/政策评价/宗教/民族
- 聚焦"技术 + 商业 + 产品"

## 📚 推荐信源
{按国内/国外/论文/报告分类}
```

## 🛠 使用步骤

1. 复制本模板
2. 替换 `{占位符}`
3. 调整采集范围 + 权重（按本 cron 领域）
4. 调整信源清单（按本 cron 关注平台）
5. 写"✅ 好样本"和"❌ 差样本"（**关键**：让 LLM 知道好/坏差别）
6. 配 cron schedule + delivery
7. 第一次跑：手动 trigger 看效果
8. 阿轩反馈 → 迭代

## 📐 4 个自检问题（设计新 cron 前必答）

1. **M1 互动信号覆盖了吗？** — 能不能搜 X/Reddit/HN 真实讨论？
2. **M2 零配置吗？** — 有没有强制要 API key？
3. **M3 禁词清单具体吗？** — "不用 AI 套话"是软建议还是具体清单？
4. **M4+M7 格式有结构锚吗？** — 首行身份锚？末尾状态条？

4 个全 ✅ 才算合格。
