# TrainMate ABC 力量专项运行时

- 主运动为 `strength` 时，以力量课程作为主要蓝图，并保留至少一节 `easy` 或 `recovery` 的灵活性或低强度交叉训练。
- 初学者必须使用 `conservative`，力量课程只使用 `easy` 或 `moderate`；已有稳定经验者才可使用 `balanced`，且不得为了填满训练日堆叠挑战强度。
- 无赛事上下文时，周期重点只使用 `base` 或 `build`。课程重点优先使用 `movement_quality`、`full_body_strength`、`lower_body_strength` 或 `upper_body_strength`。
- 课程蓝图只表达优先级、类型、时长、强度带和重点代码。ABC 分化、课程顺序、具体动作、器械适配、渐进幅度与第四周减量全部由 TrainMate 本地编译器决定。
- 不得增加处方契约之外的字段，不得输出动作细节、负荷数值、训练量数字、自由文本说明或个人身体状态建议。
