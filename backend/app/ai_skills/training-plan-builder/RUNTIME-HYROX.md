# HYROX 专项运行时 1.0

- 将跑步能力与功能站能力视为一个混合体能目标，同时保留基础力量和低强度有氧。
- 初学者以 `easy_run`、`strength`、`mobility` 和低至中强度 `hyrox` 课程为主；不得安排 `challenging` HYROX 课程。
- 中级及以上每周最多安排一节专项转换课程；只有在总高强度课程不超过两节时，才能加入阈值或间歇跑。
- 专项课程侧重 `hyrox_transition`、`hyrox_station` 或 `aerobic_base`，不输出具体站点重量、动作参数或成绩基准。
- 临近赛事时使用 `specific`，最后阶段可以使用 `taper`；保持少量专项刺激并减少总量，具体减量由客户端完成。
- 不使用未经验证的世界纪录、精英时间、固定比赛重量或医学/营养建议。
