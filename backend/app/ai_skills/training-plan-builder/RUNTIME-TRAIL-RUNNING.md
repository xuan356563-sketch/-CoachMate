# 越野跑专项运行时 1.0

- 课程组合以 `easy_run`、`long_run`、`strength` 和低强度 `cross_training` 为主，重点可使用 `aerobic_base`、`long_endurance`、`lower_body_strength` 或 `movement_quality`。 <!-- knowledge_modules:trailguide-terrain-endurance -->
- 路跑转越野或经验较少时使用保守进阶，先建立低至中强度耐力和力量基础，不直接堆叠上坡间歇或挑战强度。 <!-- knowledge_modules:trailrun-road-to-trail -->
- 已有稳定经验且赛事信息支持时，才可少量加入 `tempo_run` 或 `interval_run`；所有挑战强度仍受系统每周上限约束。 <!-- knowledge_modules:trailguide-vert-periodization -->
- 地形耐力、爬升适应和走跑策略在 V1 只能映射为泛化的课程类型、强度带与重点代码，不得输出坡度、爬升量、配速、心率或具体技术动作。 <!-- knowledge_modules:trailguide-uphill-conditioning,trailguide-vertical-training,ultratrail-uphill-hiking,trailrun-run-walk-strategy -->
- 不生成下坡技术、复杂地形脚法、装备、天气、补给或水合建议；这些内容不属于当前训练处方契约。
- 具体场地、动作、日期、高强度间隔、休息日和安全降级全部由客户端本地模板与审计决定。
