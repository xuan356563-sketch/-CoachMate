# ADR-0002：云同步保持本地优先

状态：已接受

## 背景

当前应用已在多个 `trainflow.*.v1` 键下保存本地资料、训练和健康数据。直接改为远端唯一数据源会破坏离线可用性和旧数据兼容。

## 决策

Flutter 写入路径仍先落本地；后续登录后由 outbox 按客户端 UUID 和幂等 mutation ID 推送，再以服务端游标拉取变化。资料和设置使用版本号处理冲突，记录型数据优先追加并保留修订痕迹。

## 后果

- 云端接入前不得改动既有 JSON 键名或数据格式。
- 同步失败不能阻断训练、记录、导出或安全降级。
- 首次登录必须让用户确认是否上传本机数据并说明合并规则。
