# ADR-0003：DeepSeek 通过服务端网关接入

状态：已接受

## 背景

训练资料、身体指标和疼痛记录不应直接从客户端发送给第三方模型，也不能在 Flutter 包中保存 API 密钥。

## 决策

后续仅由后端 AI 模块调用 DeepSeek。请求只包含经过用户同意和最小化裁剪的结构化上下文，响应必须校验为固定建议 schema。模型名、密钥、超时和限流均由服务端环境配置管理。

## 后果

- 原有本地规则引擎继续作为超时、限流和结果校验失败时的降级策略。
- AI 输出不构成医疗诊断；高疼痛或红线场景优先返回安全提示，而不是强度建议。
- 每次调用需要记录提示词版本、结果摘要和成本元数据，但不得在日志中泄露密钥或不必要的原始敏感内容。
