# TrainFlow Phase 1：账号与会话

## 范围

本切片只实现服务端账号基础，不修改现有 Flutter 的本地登录状态、训练闭环或 `trainflow.*.v1` 本地存储。Flutter 在下一切片才会新增登录界面、安全令牌存储和同步 outbox。

## 数据库迁移

迁移 `20260713_0002` 依赖 `20260712_0001`，新增以下表：

| 表 | 作用 | 敏感数据处理 |
| --- | --- | --- |
| `users` | 账号主体 | 保存手机号 HMAC 摘要和末四位，不保存手机号明文 |
| `user_consents` | 服务协议和隐私政策版本记录 | 保存版本、授权和撤回时间 |
| `devices` | 应用安装实例 | 保存应用 UUID、平台和用户可选设备名称，不读取硬件标识 |
| `sms_challenges` | 一次性验证码挑战 | 保存验证码 HMAC 摘要、有效期、尝试次数和消费时间 |
| `auth_sessions` | 刷新令牌和轮换关系 | 保存刷新令牌 HMAC 摘要、会话族、撤销和过期信息 |

迁移前没有云端业务表，因此不涉及旧云端数据转换。开发和测试环境可回滚；生产环境一旦存在账号或会话数据，禁止直接 `downgrade`，必须先撤销会话、导出受影响数据并完成影响评估。

## API 行为

1. `POST /v1/auth/sms-challenges` 只返回挑战 ID 和有效期，不返回验证码。
2. 新手机号在 `POST /v1/auth/sessions` 时必须提交服务协议与隐私政策版本，验证码在缺少同意时不会被消费。
3. 会话返回 15 分钟访问令牌与 30 天刷新令牌。刷新时生成新令牌；旧令牌被重放会撤销同一会话族。
4. `GET /v1/auth/me` 不返回手机号明文；退出接口撤销当前会话，使访问令牌立即失效。

## 腾讯云短信

短信接口通过 `tencentcloud-sdk-python` SDK 3.0 调用腾讯云 `SendSms`。默认实现为禁用状态，避免本地开发、测试或未完成签名/模板审核时误发短信。

启用前必须在腾讯云完成应用、签名和模板配置，并通过部署平台注入 `TENCENT_*` 密钥。模板参数顺序固定为验证码、有效分钟数。不得在 Flutter、Git、日志、测试样例或 API 响应中保存验证码和云密钥。
