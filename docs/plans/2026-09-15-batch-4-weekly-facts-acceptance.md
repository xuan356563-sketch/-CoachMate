## 审查发现与修复

|问题|修改|
|---|---|
|0% 完成也计入课程全部训练维度；有动作明细仍优先套课程维度|零完成不贡献维度。有明细时只读取已完成组数大于 0 的动作；无明细时，仅整课 100% 完成记录沿用课程维度，部分完成不猜测维度|
|50% 完成在现状中四舍五入为一次完成，Markdown 分子与完成率不一致|现状保留 0.50 等折算值，Markdown 展示完成率及计划目标；说明是记录比例折算，不是完整训练次数|
|空白复盘对象被当成恢复证据，显示“常规”|没有准备度或任何有效评分时显示“无法评估”；仅备注不构成评分证据|
|补录以写入时间进入近七天统计|按训练日期过滤近七天，同时排除未来训练和未来写入；明确观察窗口不是自然周累计|
|所有会话都标成手动记录|按现有记录类型分别展示手动、跟练后手动反馈、引导训练和活动导入数量，不宣称这些类型等于经过真实性验证的测量|
|维度的“1/0”容易被误读为完成率|页面与 Markdown 明确分开“实际记录 1 次，计划 0 次”|

不改变训练生成器、准备度公式或心理信号阈值。维度映射复用既有动作画像，表示记录中的训练维度，不表示动作质量或生理进步。原 `completedWorkouts` 整数字段保留兼容，新展示不再把该四舍五入值当作精确完成单位。没有修改报告 JSON 结构；已保存旧报告不自动重算或重写。
