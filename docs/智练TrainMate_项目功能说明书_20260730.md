## 1. 产品原则

1. 健康、疼痛、身体指标和恢复判断优先在本机处理。
2. AI 只能生成提议；画像、计划和周期重排必须由用户确认后生效。
3. 训练建议必须通过本地安全规则二次审计。
4. 优先使用本地模板和缓存，只有无法确定时才调用云端。
5. 来源引用由服务端回填和校验，模型不能自行编造引用 ID。

| 模块 | 当前功能 | 数据位置与边界 |

| 知识库 | 已审核原则、训练模板、来源定位和正常页面入口 | 不复制版权正文 |

## 4. Token 与模型状态

- 默认文本模型：`deepseek-v4-flash`，环境变量可覆盖。
- Recovery：始终本地处理，0 Token。
- 对话：最近 4 条，正文合计不超过 1200 字符，输出不超过 420 tokens。
- 画像：输入不超过 1800 字符，输出不超过 320 tokens。
- 月度处方：输入不超过 4200 字符，输出不超过 650 tokens。
- 周期重排：动态上下文不超过 2200 字符，输出不超过 650 tokens。
- 当前只有字符预算、模拟 usage 和缓存测试证据；没有真实 API 调用基线，不能宣称 45% Token 降幅已经达成。

## 6. Android 包标识注意事项

Android `namespace` 与 `applicationId` 已由 `com.example.trainflow_ai` 改为 `com.zhilian.trainmate`。当前没有连接 Android 设备，也没有证据表明旧包已正式分发，因此无法检查某台设备中的旧沙箱数据。

Android 会把新 Application ID 视为另一个应用，旧包的本地数据不会自动迁移。若测试设备仍装有旧包，应先保留旧包并导出需要的数据，再安装新包；不要直接卸载旧包。
