# TrainFlow AI 深蓝橙视觉设计规范

## 设计目标

TrainFlow AI 使用运动决策工具的业务结构，采用深海军蓝、纸白和蜜桃橙构成的插画式界面。视觉语言参考波形页面、粗描边卡片、圆形日期和高对比底部导航，但不复制参考作品中的角色、文案和业务内容。

## 核心色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 深海军蓝 | `#19172C` | 页面结构、描边、主文字、底部导航 |
| 纸白 | `#FFFDFC` | 卡片、输入框、反白文字 |
| 蜜桃橙 | `#FFB27D` | 主按钮、选中态、关键视觉提示 |
| 浅桃 | `#FFE2B8` | 重点卡片、指标底色、筛选选中态 |
| 页面灰 | `#F4F2F5` | 移动画布背景 |
| 正文黑 | `#181722` | 正文和数据文字 |

红、黄、绿只表达疼痛风险、训练警告和完成状态，不作为品牌主色。

## 版式与组件

- 移动端使用全宽画布；桌面 Web 将画布限制在 `430px` 并居中，外围保持深海军蓝。
- 页面左右留白为 `16px`，卡片圆角为 `8px`，边框为 `1.5px` 深海军蓝。
- 页面默认使用有机波形头部；信息密集的特殊页面可使用紧凑头部，无标题流程可关闭头部。
- 筛选器、状态标签、日期和头像使用圆形或胶囊形；业务卡片保持矩形，不使用卡片嵌套。
- 主按钮使用蜜桃橙底、深蓝字和深蓝描边；次按钮使用纸白底和深蓝描边。
- 字体优先使用系统中文字体，回退顺序为苹方、Noto Sans CJK SC、微软雅黑和系统无衬线字体；字距固定为 `0`。

## Flow 运动伙伴

Flow 是原创的无动物特征运动伙伴：深蓝软团形身体、白色软胶囊面部显示区、蜜桃橙运动头带和配件、深色粗描边。品牌常态脸把左点眼与右弯眼放在胶囊内，蜜桃橙短嘴放在胶囊正下方并与胶囊下缘保持明显留白，同时保留头带软结与两条不等长短飘带。角色按训练、恢复、比赛、首次引导和空状态切换配件与表情，不承载业务数据，也不替代可访问性文字。

## 动效

| 场景 | 时长 | 规则 |
| --- | --- | --- |
| 页面转场 | `220ms` | 淡入并上移 `12px` |
| 内容入场 | `220ms` | 每项错峰 `40ms`，总延迟不超过 `100ms` |
| 数值变化 | `450ms` | 使用平滑插值 |
| 按钮反馈 | `120ms` | 仅缩放或颜色反馈 |
| 标签切换 | `160ms` | 颜色和边框过渡 |
| 顶部波形 | `6s` | 单次低幅呼吸，位移不超过 `3px` |

系统开启“减少动态效果”后，页面转场、内容入场和角色位移全部直接展示最终静态状态。

## 页面映射

- 今日训练：计划主页，突出今日状态、训练内容、完成记录和 AI 教练建议。
- 训练计划：日历追踪，先显示七日训练节奏，再显示计划方案。
- 动作库：内容网格，动作检测置顶，训练动作使用双列卡片。
- 比赛：赛程追踪，集中展示导入、排期、减量、策略和恢复。
- 我的：档案与健康统计，集中资料、康复、身体数据、营养和训练负荷。

## 验收尺寸

- `393 × 852`：主要手机验收尺寸。
- `430 × 932`：大屏手机验收尺寸。
- `1200px` 桌面宽度：检查移动画布居中和深蓝外围背景。
