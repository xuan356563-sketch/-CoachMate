# TrainMate 参考图设计语言分析（应用规则）

> 来源：游戏化阅读/成长应用参考图（浅色深紫 + 高饱和多色）。
> 原则：借鉴设计语言，不用参考图的波斯语/RTL/插画角色/品牌元素，中文使用 LTR、原创素材。

## 一、颜色规则

| 角色 | 色值 | 用法 |
|---|---|---|
| 品牌深紫 | `#191331` | 深色底、深色按钮、选中态圆底 |
| 主紫 | `#6C3DF4` | 主操作、选中高亮、进度主线 |
| 黄 | `#FFD54A` | 高亮卡底、提醒、等级进度 |
| 粉 | `#F083C6` | 数据强调、卡底、头像圈 |
| 蓝 | `#438CF5` | 数据强调、信息蓝 |
| 薄荷绿 | `#67E6B1` | 完成态、成功、勋章 |
| 珊瑚 | `#FF665B` | 错误、警示 |
| 白 | `#FFFFFF` | 卡片 / 浅色底 |
| 暖灰 | `#F6F6F4` | 浅色页面底 |

- **深/浅双态**：深紫底上放白/紫/粉内容；浅灰底上放白卡 + 彩色强调。
- **高饱和彩色只做功能强调**，不铺满整页；彩色卡（黄/粉/蓝）作为插画/成果卡。

## 二、字号 / 排版

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 超大数字 | 34–40 | w700 | 指标主值（步数/时长/百分比） |
| 标题 | 22–28 | w700/w600 | 页标题、卡片标题 |
| 大数字单元 | 14–16 | w600 | 超大数字旁边的单位/副值 |
| 正文 | 14–16 | w400 | 说明 |
| 说明 | 12 | w400 | 辅助、时间、标签 |

- **主值远大于单位**（如「26480 `step`」），形成强对比。
- 数字用 `w700`，单位 `w400`，短标签。
- 关键指标数字用较大字号，二级标签小号。

## 三、排版 / 布局

- **卡片模块化**：内容以圆角卡片（20–32px）组织，非对称。
- **突出数据块**：一个高亮块放「主值 + 副值 + 百分比 + 计时」。
- **色块 + 插画卡**：黄/粉/蓝底卡承载插画 + 文案。
- **进度可视化**：分段进度条 / 环形 / 圆点，颜色分段（紫/黄）。
- 装饰圆点/散点只做氛围，不遮挡内容。

## 四、组件

- **高亮统计面板**：彩色底（紫/粉）+ 大数字 + 单位 + 百分比 + 计时。
- **分段进度条**：两种颜色（紫→黄/粉），显示当前值。
- **条形图卡**：深色卡 + 彩条（蓝/黄/粉），日期轴。
- **插画卡**：纯色底（黄）+ 扁平插画 + 标题/时间。
- **任务/分类卡**：彩色胶囊图标 + 时长/次数 + 深紫「选择」按钮。
- **头像**：圆形头像 + 粉色描边圈 + 昵称 + 等级/战绩。
- **记录卡**：名次 + 数值 + 图标（书本/奖杯）。
- **彩色圆点**：多色圆点作选择/状态（紫/蓝/红/橙/绿）。

## 五、描边 / 质感

- **卡片基本无描边**，冷阴影很轻，靠颜色和层级区分。
- 大圆角（20–32px），胶囊按钮（999）。
- 彩色底卡（黄/粉/蓝）无边框；白卡在彩色底上圆角大。
- 描边只用于图标按钮（细灰/深紫描边），卡片采用无边框 + 轻阴影。

## 六、导航栏

- 浅色（白）悬浮胶囊/圆弧，圆角大。
- 5 个线性图标 + 文字标签；选中态用深紫/紫高亮。
- 中央为强化项（凸起 hero）。视觉与当前 CoachMate 导航 v2 一致。

## 七、应用到当前设计的改造点

1. **首页主数据卡**：用「高亮统计面板」+ 大数字 + 百分比 + 计时 + 分段进度（紫/黄）。
2. **数据/成长**：用分段进度 + 圆点/小环表示等级进度；多色强调。
3. **头像**（我的页）：圆形头像 + 粉色描边圈 + 等级/战绩。
4. **插画卡**：用原创扁平插画 + 纯色底（黄/粉/蓝）做成果/故事卡。
5. **多色功能**：统一 `EmpBadge` 多色语义（已建），数据与状态用黄/粉/蓝/薄荷绿/珊瑚。

> 注意：保留业务正确性、LTR、中文、原创素材；高饱和仅做强调，不降低可读性。
