# CoachMate 五主标签参考图设计语言

> 适用范围：`计划｜今日｜伙伴｜动作库｜我的` 五个生产主标签及共享底部导航。
>
> 参考图只提供姿态、字号、布局、组件、颜色、描边与导航语言；不复制其中的波斯语、人物、品牌、营销背景、倾斜手机或虚构数据。

## 1. 视觉核心

五张参考图的共同特征不是某一张卡片，而是一套稳定的页面节奏：

1. 首屏使用纸白或单一高饱和色承载主信息，不使用复杂场景图抢占层级。
2. 关键数据以不对称、相互重叠的胶囊和圆角面板呈现。
3. 页面中段通过柔和波浪从纸白数据区过渡到深紫行动区。
4. 深紫区只放当前最重要的任务、挑战或下一步操作。
5. 次级内容采用两列短卡、横向露出卡或简洁记录行，避免所有信息都变成同样的全宽卡片。
6. 插画负责传达状态和动作，不承载业务文字；所有中文与真实数值由 Flutter 渲染。

## 2. 色彩规则

| 语义 | 色值 | 用法 |
|---|---|---|
| 深紫墨色 | `#191331` | 行动区、底部导航、深色指标面板 |
| 主紫 | `#6C3DF4` | 主进度、选中态、当前位置 |
| 纸白 | `#F7F6F2` | 页面数据区与大面积留白 |
| 亮黄 | `#FFD54A` | 今日主任务、奖励、重点进度 |
| 粉色 | `#F083C6` | 关系、情绪与次级指标 |
| 蓝色 | `#438CF5` | 信息、检测和数据入口 |
| 薄荷绿 | `#67E6B1` | 已完成、恢复良好等正向状态 |
| 珊瑚红 | `#FF665B` | 风险、警示与需要关注的状态 |

- 高饱和色用于关键状态、指标、插画卡和主行动，不铺满长页面。
- 普通信息卡保持纸白或极浅灰，层级主要依靠明度与间距。
- 不同时叠加渐变、描边、重阴影；页面不使用大面积玻璃模糊。
- 可使用同色低透明度线稿作为氛围纹理，但不得降低文字可读性。

## 3. 字号与数字层级

| 层级 | 字号 / 字重 | 用法 |
|---|---|---|
| 页面标题 | `26–28 / w700` | 五主标签首屏标题 |
| 分区标题 | `20–22 / w700` | 训练、健康、记录等一级分区 |
| 卡片标题 | `16–18 / w600` | 任务卡、记录卡与功能入口 |
| 核心数值 | `34–40 / w700` | 完成率、准备度、时长、次数 |
| 正文 | `14–16 / w400` | 说明与真实状态 |
| 单位 / 辅助 | `11–13 / w400–600` | 分钟、次数、日期、来源 |

- 核心指标采用“大数值＋小单位＋短标签”三层结构，单位与数字基线对齐。
- 中文标题保持短句，不把解释性长文塞入首屏卡片。
- 两倍文字缩放时，双列必须变为单列；导航标签限制缩放但语义保持完整。

## 4. 布局与组件

### 4.1 页面节奏

- 页面最大画布保持 `430dp`。
- 常规页面边距 `20dp`，卡片间距 `12–16dp`，卡内边距 `16–20dp`。
- 首屏优先顺序：身份或日期 → 核心指标 → 当前任务 → 次级状态。
- 波浪分界应在首屏或紧随首屏出现，不放在全部长内容之后。
- 横向内容允许露出下一张卡片，明确提示可以继续浏览。

### 4.2 圆角与描边

- 展示卡圆角 `28–32dp`。
- 普通卡圆角 `20–24dp`。
- 控件圆角 `14–16dp`，标签胶囊使用全圆角。
- 普通卡默认无描边；筛选器、日期格和图标按钮使用 `1.5–2dp` 深紫描边。
- 阴影只使用低位、低透明度紫灰，不使用外发光或厚重悬浮阴影。

### 4.3 标志性组件

- **重叠指标胶囊**：一个彩色主数值面板叠在深紫或纸白副指标面板上。
- **分段进度**：紫、黄或功能色分段，显示当前值与目标，不生成不存在的历史数据。
- **彩色行动卡**：黄、蓝、粉、珊瑚或薄荷底，配扁平 CoachMate 姿态和一个明确操作。
- **双指标面板**：深紫圆角面板内左右两个真实指标，中间使用低对比分隔线。
- **记录行**：图标、标题、辅助说明和右侧真实值；不把每一行做成大型展示卡。
- **状态面板**：加载、空数据、错误、未授权和图片失败使用同一结构，并明确说明当前没有写入数据。

## 5. CoachMate 姿态规则

- 五主标签使用已有扁平 CoachMate 素材，保持纸袋、右侧绑带、宴席印花、琥珀眼睛、爱心舌头和陶土色身体。
- 角色在首屏应有清晰动作剪影，主体通常占内容宽度约 `35%–45%`，周围保留足够留白。
- 推荐映射：
  - 计划：指向引导、单腿平衡。
  - 今日：跑步、高抬腿、开合跳。
  - 伙伴：盘腿冥想、指向引导。
  - 动作库：侧弓步拉伸、深蹲、坐姿前屈。
  - 我的：以头像或静态身份形象为主，不重复展示多个全身角色。
- 同一首屏只设置一个主角色；图片失败时继续使用现有 C-08、Flow V2 和旧 Flow 回退链。

## 6. 五页映射

### 计划

- 纸白上区展示日期轨道、当前周期、计划名称和真实排期。
- 深紫区放唯一主操作，以及四周阶段、比赛备战、待确认建议和跟练入口。
- 空排期明确显示“尚未安排”，计划生成和结构调整仍需用户确认。

### 今日

- 上区用重叠胶囊展示完成率、准备度、预计时长和本周一致性。
- 波浪下方优先显示亮黄今日训练卡与开始／继续操作。
- 睡眠、疲劳、酸痛、情绪和最近记录只展示真实数据；缺失时显示“待记录”。

### 伙伴

- 首屏由一个 CoachMate、成长阶段、关系状态和最新可信消息组成，不重复出现第二个大角色。
- 下区排列消息、行动、事实来源、Coach 输入、记忆与成长档案。
- 首次选择、只读、空消息、加载和错误状态继续保留。

### 动作库

- 上区展示真实动作总量、搜索、动作检测和焦点筛选。
- 部位、小肌群、功能性与膝踝循环可使用两列高饱和插画卡。
- 239 个动作、滚动恢复、检测结果和动作详情保持原有业务结构。

### 我的

- 使用“居中头像 → 姓名与训练目标 → 深紫双指标面板 → 黄紫成长进度 → 简洁记录行”的顺序。
- 内容按训练、健康、成长、账号分组，减少身份、指标和角色的重复展示。
- 健康、睡眠、同步和负荷没有授权或数据时，必须显示真实空态。

## 7. 底部导航

- 固定五项顺序保持：`计划｜今日｜伙伴｜动作库｜我的`。
- 使用深紫一体式圆角底栏，未选中项只显示象牙白线性图标。
- 选中项使用白色或亮黄色圆角胶囊，并显示短中文标签；不保留永久中央大球，也不依据索引改变业务身份。
- 选中胶囊在五个固定槽位间连续移动，约 `320ms`；快速反向从当前插值继续。
- 按压反馈约 `120ms`；系统关闭动画时直接显示最终位置。
- `320dp` 宽度下每项仍保持至少 `48×48dp` 点击区，“动作库”不得被截断。
- 底栏阴影保持轻微，仅用于与内容区分层，不使用玻璃强模糊或大面积光晕。

## 8. 真实数据与产品边界

- 页面上的姓名、日期、训练、计划、健康、伙伴和成长数据继续来自现有 Provider。
- 不复制参考图中的步数、计时、排行榜、热量、头像、语言或挑战数据。
- 无数据时显示“待记录”“未授权”或“暂无数据”，不得补造历史趋势。
- 不修改路由、数据库、API、健康授权、认证、云同步或训练业务。
- AI 只能提出建议；计划、调整和数据写入仍需用户明确确认。
- 登录、详情、表单、报告和播放器不在本轮主标签视觉迁移范围内。
