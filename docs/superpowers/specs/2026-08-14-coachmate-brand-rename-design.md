# 练搭 CoachMate 品牌直接切换设计

## 状态

- 日期：2026-08-14
- 结论：已确认采用用户可见品牌直接切换
- 正式名称：练搭 CoachMate
- 中文短名称：练搭
- 英文名称：CoachMate
- 品牌口号：练，有人陪。

## 背景与目标

当前应用的用户可见名称仍以“智练 TrainMate”或“TrainMate”为主，分布在 Flutter 页面、无障碍文案、本地通知、登录邮件、iOS、Android、Web 和 StoreKit 配置中。新的产品定位是本地优先、长期陪伴的 AI Coach agent／运动搭子，而不是传统课表型健身应用。

本次改名的目标是：

1. 将所有本轮覆盖的用户可见品牌名称直接切换为“练搭 CoachMate”。
2. 在紧凑场景使用“练搭”，在英文限定场景使用“CoachMate”。
3. 在登录等主要品牌入口展示“练，有人陪。”。
4. 保留既有发布身份、数据库和本地数据兼容性，使旧版本用户升级后继续使用原有账号与数据。
5. 建立集中品牌常量和跨端品牌契约测试，降低后续文案漂移风险。

## 品牌基础

### 产品定位

练搭 CoachMate 是本地优先的个性化训练应用，核心是长期陪伴的 AI Coach agent／运动搭子。它基于用户已有的训练、活动、恢复和安全事实提供陪伴与可确认建议，不以自律说教、身材焦虑或课表堆砌驱动使用。

### 目标人群

- 想长期坚持运动，但不想靠自律硬扛的人。
- 厌倦健身应用贩卖自律和身材焦虑的人。
- 希望训练应用理解疼痛、恢复和疲劳状态的人。
- 主要面向 20～40 岁、有训练诉求并愿意与 AI 建立长期关系的人群。

### 品牌语气

- 温暖，但不哄骗。
- 克制，不制造焦虑。
- 可信，训练事实和安全边界可追溯。
- 不评判，不用羞耻或纪律评价推动训练。
- 尊重用户控制权，建议必须由用户确认后生效。

## 命名契约

| 场景 | 使用名称 | 示例 |
| --- | --- | --- |
| 应用商店、登录页、协议标题、系统应用名称 | 练搭 CoachMate | 登录练搭 CoachMate |
| 通知标题、窄屏或空间受限位置 | 练搭 | 打开练搭查看今日安排。 |
| 明确只接受英文的元数据 | CoachMate | CoachMate Membership |
| 主要品牌入口 | 正式名称＋口号 | 练搭 CoachMate／练，有人陪。 |
| 伙伴角色 | 继续使用具体伙伴名 | 衡衡狸有话想对你说 |

所有新增用户可见文案优先从集中品牌常量读取。平台配置无法读取 Dart 常量时，由测试校验其值与品牌契约一致。

## 方案选择

### 采用：用户可见品牌直接切换

修改 Flutter 界面、通知、邮件和三端元数据；保留内部技术身份。该方案能在不影响升级兼容性的前提下完成品牌切换。

### 不采用：全栈重命名

不修改 Bundle ID、Android applicationId、Dart 包名、数据库表、内部类名、HealthKit 存储目录、环境变量和历史模型编号。修改这些内容可能导致应用被识别为新产品、旧数据无法读取或外部部署配置失效。

### 不采用：过渡双品牌

不展示“原 TrainMate”或双品牌过渡文案。用户已确认直接切换。

## 组件与职责

| 组件 | 输入 | 输出 | 约束 |
| --- | --- | --- | --- |
| `AppBrand` | 已确认的名称与口号 | Flutter 可复用品牌常量 | 不包含路由、数据或业务逻辑 |
| Flutter 用户界面 | `AppBrand` | 页面标题、按钮、协议、错误和无障碍文案 | 不改变页面结构和业务流程 |
| 通知层 | 正式名称或短名称 | 本地训练通知、伙伴通知 | 紧凑标题使用“练搭”，隐私口径保持不变 |
| 后端邮件模板 | 正式名称 | 验证码邮件主题和正文 | 不修改认证接口、验证码逻辑或环境变量 |
| iOS／Android／Web 元数据 | 品牌契约 | 系统桌面名、网页标题和安装信息 | 保留发布身份和图标路径 |
| StoreKit 展示配置 | 正式名称、英文名称 | 用户可见会员名称 | 产品 ID 和内部 referenceName 保持不变 |
| 品牌契约测试 | 允许范围和兼容白名单 | 跨端一致性检查 | 不以全仓字符串替换破坏内部标识 |

## 用户可见修改范围

### Flutter

- `MaterialApp` 标题。
- 登录页、登录按钮、协议页、年龄提示和服务连接错误。
- 主要品牌组件的无障碍名称。
- 数据删除、训练安全和屏幕常亮提示中的产品名称。
- 本地训练通知和伙伴通知标题、正文。
- 登录主品牌区域增加“练，有人陪。”。

现有登录锁定图包含“智练 TrainMate”文字，运行时不再展示该旧锁定图。登录页改为复用不含旧文字的品牌头像，并由 Flutter 文本绘制“练搭 CoachMate”和口号。旧图片作为历史资产保留，不删除、不覆盖。

### iOS

- `CFBundleDisplayName` 和用户可见的 `CFBundleName` 改为“练搭 CoachMate”。
- StoreKit 本地化会员展示名改为“练搭 CoachMate 会员”。
- StoreKit 英文展示名改为“CoachMate Membership”。
- 产品 ID、Bundle ID、Scheme 和签名配置保持不变。

### Android

- Launcher 应用名称改为“练搭 CoachMate”。
- applicationId、Kotlin 包路径、备份规则文件名和图标资源名保持不变。

### Web

- 页面标题、安装名称和 Apple Web App 标题改为“练搭 CoachMate”。
- 页面描述改为“练搭 CoachMate：本地优先的 AI Coach agent 与运动搭子，陪你长期训练。”
- 路由、缓存、图标路径和部署域名保持不变。

### 后端

- 登录验证码邮件的主题和正文改用“练搭 CoachMate”。
- 内部 AI Prompt、运行时规则名、知识来源标识、部署环境变量和脚本参数保持不变；它们不是用户可见品牌展示面，本轮不做高风险批量替换。

## 明确不在本轮范围

- 不修改 App 图标、衡衡狸或 Flow 形象。
- 不重新设计颜色、字体、页面布局或底部导航。
- 不重命名仓库、目录、代码文件、Dart 类型或测试类型。
- 不修改 Bundle ID、applicationId、数据库路径、表结构或迁移版本。
- 不批量改写历史计划、验证报告和已冻结项目文档。
- 不直接修改 App Store Connect、邮件发件人域名、官网域名或线上部署配置；这些外部系统需要后续人工发布操作。
- 不在本轮对“练搭”或“CoachMate”作商标、域名及应用商店名称可用性结论；正式商业发布前需单独完成检索与人工审核。
- 不在本次改名中夹带“删除消息记录”或“收起键盘”功能实现。

## 兼容性与数据安全

- 本次没有数据库迁移，现有训练、健康、伙伴、记忆和账号数据不变。
- 保留 `com.zhilian.trainmate`，系统将新版本识别为同一个 iOS 应用。
- 保留 Android applicationId，Android 升级路径不变。
- 保留 HealthKit 和本地安全存储键名，避免重新授权或读取不到旧数据。
- 保留 StoreKit 产品 ID，现有订阅测试配置继续可识别。
- 回滚只需安装或发布上一版本应用，不执行 SQLite 或 Alembic 降级。

## 错误处理与降级

- 品牌头像加载失败时继续使用现有头像回退资源，但回退区域不得显示旧品牌文字。
- 平台元数据若未同步，将由品牌契约测试失败阻止验收。
- 登录邮件改名不改变发送失败、重试和验证码错误处理。
- 通知改名不改变权限、隐私等级、时区和通知调度规则。

### 构建与人工验证

1. 运行受影响的 Flutter 聚焦测试和静态分析。

3. 进入登录页，确认不再显示旧锁定图文字，并显示“练搭 CoachMate／练，有人陪。”。

6. 如当前环境具备条件，补充 Web 构建；Android 无 SDK 时只报告静态契约结果，不声称 APK 构建通过。
