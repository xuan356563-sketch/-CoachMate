# TrainMate Flow V2 高饱和精修设计

## 目标

恢复 2026 年 7 月版本的无动物特征深蓝软团 Flow，替代当前运行时优先加载的 Flow Dog。角色只做颜色、表情和器材细节增强，不改变轮廓、动作、比例或业务映射。

## 不可变身份锚点

- 保留深蓝软团身体、白色胶囊脸、蜜桃头带及不等长飘带、细线四肢。
- 保留现有 20 个 `TrainMateAction` 的编号、姿态、器械、文件名和页面语义。
- 不增加耳朵、尾巴、鼻口等动物特征，不使用兔子、小犬或其他候选角色。
- 角色始终为单人、透明背景、无文字、无 Logo、无水印；浅深背景版本均为 `512×512` RGBA。
- 原始旧 Flow 素材保持原位、只读保留，作为第一回退和轮廓比对基线。

## 色彩与细节

深蓝主体继续承担品牌识别，高饱和色只用于内部光影、头带、表情符号、器材和动作状态：

| 用途 | 色值 |
| --- | --- |
| 主体基色 | `#19172C` |
| 主体高光 | `#4B4EC8` |
| 主体阴影/描边 | `#0E0D1B` |
| 纸白面板 | `#FFFDFC` |
| 珊瑚橙 | `#FF6B4A` |
| 杏桃高光 | `#FFB25B` |
| 晴日黄 | `#FFD447` |
| 薄荷青 | `#42D9C1` |
| 天空蓝 | `#55B8FF` |
| 活力紫 | `#8B72FF` |
| 腮红 | `#FF8FA3` |

- 引导使用天空蓝和晴日黄；速度动作使用珊瑚橙和薄荷汗滴；力量动作使用活力紫和晴日黄；恢复动作使用薄荷青和天空蓝；庆祝动作允许四色小面积彩点。
- 增加两级主体光影、瞳孔高光、眉形、嘴型、腮红、汗滴、星点、鞋带、器械高光和布料折线。
- 装饰不得突破原透明轮廓；除既有跳绳、哑铃等器械外，不新增场景道具。
- `16/24/32/48px` 小尺寸优先保证胶囊脸、头带和主体轮廓，不保留无法辨识的微细节。

## 素材与运行时架构

- 新建 `assets/branding/flow-v2-color-detail/`，包含品牌导出图、20 动作双背景版、源母版、联系表和 `manifest.json`。
- 使用图像编辑工具基于旧 Flow 原图进行分层精修；以原图 Alpha 蒙版约束输出，再使用现有图片处理方式统一裁切、安全区和尺寸。
- `TrainMateBrandAssets` 与 `TrainMateActionAssets` 的主路径切换到 V2；旧 Flow 路径作为第一回退。Flow Dog 和仓库外候选图保留但不再作为运行时主路径。
- `FlowMascotAction`、`FlowMascotExpression`、`TrainMateAction`、语义标签、动效、页面状态选择函数和路由接口全部保持不变。
- iOS、Android、Web 图标切换为 V2 品牌标；建立新的原生资源名称，不覆盖 Flow Dog 原文件。

## 视觉审批门

1. 先输出主头像、6 种核心表情以及指引、跑步、冥想、力量 4 个代表动作的联系表。
2. 仅在联系表确认后批量生成 20 动作双背景版、组合标和全平台图标。
3. 批量结果逐张进行轮廓、肢体、器械、表情和小尺寸检查；不合格图只重做对应文件。

## 安全与发布边界

- 当前工作区存在大量未提交和未跟踪内容；禁止 `git reset`、`git checkout --`、批量删除或覆盖旧素材。
- 新版 manifest 记录每个源文件与输出文件的 SHA-256、尺寸、Alpha、安全区、提示词版本和人工审核状态。
- 只使用现有 TrainMate 旧 Flow 作为图像输入，不使用用户此前提供的第三方角色截图。
- 状态在人工相似性和权利审核前保持 `pending-human-visual-review`，不声明“零版权风险”。

## 验收标准

- 40 张动作图均为 `512×512` RGBA，透明背景、单一完整角色、无裁切。
- 新旧对应图 Alpha 轮廓 IoU 不低于 `0.985`，主体边界最大偏移不超过 `2px`。
- 20 个动作文件名、姿态和器械一一对应；浅深背景版本只改变对比处理，不改变动作。
- 登录、引导、今日、计划、动作库、比赛、个人页和播放器显示 V2；加载失败时显示旧 Flow。
- 品牌头像、组合标和 iOS/Android/Web 图标使用同一角色版本并通过小尺寸可辨识检查。
- 不修改训练数据、Provider、路由、健康授权、认证、订阅或 AI 确认边界。
