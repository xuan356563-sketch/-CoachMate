## 0. 验收前置

- [ ] 已归档并上传 TestFlight 版本（`flutter build ipa` 产物，Bundle ID `com.zhilian.trainmate`）
- [ ] 安装包来自 TestFlight（非 Xcode 直连调试）
- [ ] 生产后端已部署且 `TRAINFLOW_API_BASE_URL` 为真实 HTTPS 域名
- [ ] 验收设备：真实 iPhone（记录型号与 iOS 版本）
- [ ] 记录 TestFlight 构建号与 Git 提交号（`git rev-parse HEAD`）

---

## 1. 账号与安全（阻断项）

- [ ] 邮箱验证码登录成功
- [ ] 令牌刷新（App 冷启动后保持登录）
- [ ] 退出登录成功
- [ ] 重新登录成功
- [ ] 账号切换：切换前必须确认；确认后清除本地业务数据但保留安装 ID
- [ ] 登录失败提示合理、无敏感信息泄露
- [ ] 服务不可用时（断网）有明确降级提示，不崩溃

## 2. 数据安全（阻断项）

- [ ] SQLite 升级：升级前生成备份；升级后旧数据保留、`foreign_key_check` 无结果
- [ ] 打开/文件保护失败时进入只读恢复，不读取陈旧副本、不清库绕过
- [ ] 数据导出（JSON）成功且内容可读
- [ ] 账号删除：二次确认 → 云端数据清除 → 本地业务数据清除但安装 ID 保留
- [ ] 清除身体数据与清除导出记录是独立操作

## 3. 权限拒绝降级（阻断项）

- [ ] HealthKit 权限**拒绝**后 App 正常使用其他功能
- [ ] HealthKit 权限**部分授权**（仅部分数据类型）时安全降级
- [ ] 相机权限拒绝后赛事/动作图片功能安全降级
- [ ] 相册权限拒绝后安全降级
- [ ] 麦克风/语音识别权限拒绝后 AI Trainer 文字输入仍可用

## 4. 核心功能闭环（阻断项）

- [ ] 首次进入：基础资料填写（职业/生活分型、作息、器械）→ 本地持久化 `user_profile`
- [ ] 今日训练页：晨间报告、恢复倒计时、CTL/ATL/TSB 曲线正常
- [ ] 训练计划：列表 → 详情 → 规则审计展示 → 训练日详情
- [ ] 计划调整：修改单日时长/强度 → 持久化 `plan_adjustments` → 恢复原计划
- [ ] 跟练播放器：真实倒计时、暂停/重置、完成/跳过/"太累了"降级、步骤写日志
- [ ] 训练后复盘：实际时长、完成度、RPE、动作组数/重量保存
- [ ] 身体数据：10 秒快录、补录、异常值二次确认、同日覆盖留痕、7/30/90 趋势
- [ ] 每日签到：5 项/2 项动态切换、"和昨天一样"
- [ ] 周报：生成、Markdown 导出、PNG 图片卡片、本地归档
- [ ] AI 中心：AI Trainer 对话（文字+语音转写确认）、AI Motion 图片复核、AI Recovery 健康摘要同意后发送
- [ ] AI 卡片全部待确认；确认后影响训练；疼痛红线（≥7 强制休息）优先于 AI

## 5. 订阅（如 PO 决策启用）

- [ ] 沙箱环境：购买月度订阅成功
- [ ] 恢复购买成功
- [ ] 权益校验：服务端 entitlement 状态正确（active/trial/grace）
- [ ] 取消订阅后当期权益保留至周期结束

## 6. 后台与通知（如启用）

- [ ] 系统本地通知（训练提醒等）触发正确
- [ ] App 进入后台再恢复，状态不丢失

## 7. 14 天自用验收（Gate A）

- [ ] 连续 14 天逐日记录：身体数据、计划确认、训练执行、反馈、30 天引导检查、阻断问题
- [ ] 14 天后由人工执行 Gate A 复核
- [ ] 记录写入本地 `self_use_acceptance`，未来日期不可提前写入
