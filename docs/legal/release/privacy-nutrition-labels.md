# 练搭 CoachMate 隐私营养标签 / 年龄分级 / 出口合规申报表

> 版本：1.0（待上线）
> 用途：App Store Connect「App 隐私」与「年龄分级」问卷填写依据，以及出口合规声明
> 原则：**如实申报**。苹果会抽查，申报与实际不符会被拒审或下架。

## 一、App 隐私（App Privacy）营养标签申报

> 在 App Store Connect → App 隐私 → 数据收集，逐项勾选。以下按你收集的数据归类。

### 1.1 用于追踪你的数据（Data Used to Track You）

| 数据 | 是否申报 | 说明 |
| --- | --- | --- |
| 跨 App/网站追踪 | **否（不申报）** | 你的 App 不接入广告 SDK，不做跨 App 追踪；不要勾选任何"追踪"项。若后续接归因 SDK（如 AppsFlyer），需重新申报。 |

### 1.2 与你关联的数据（Data Linked to You）

> 判断标准：数据能否关联到登录后的账号身份。

| 数据类别 | 是否收集 | 是否关联 | 申报项 |
| --- | --- | --- | --- |
| 联系信息（邮箱） | ✅ | ✅ | 联系信息 → 电子邮件地址（用于账号功能） |
| 健康与健身（Health & Fitness） | ✅ | ⚠️ 本地为主 | 健康与健身 → 健康（用于 App 功能；健康数据不上云的部分仍属"收集"范畴，如实申报"收集"+"关联"） |
| 身体数据（体重/心率/HRV/睡眠/疲劳） | ✅ | ⚠️ 本地为主 | 健康与健身 → 健身与锻炼（或并入健康项） |
| 用户内容（训练日志/复盘/反馈） | ✅ | ✅ | 用户内容 → 用户生成内容 / 用户反馈 |
| 购买记录（订阅） | ✅ | ✅ | 购买记录（通过 Apple 处理，仍申报"收集"） |
| 使用数据（功能使用统计） | ✅ | ✅（如接统计） | 使用数据 → 产品互动 |
| 诊断数据（崩溃日志） | ✅ | ✅（如开启） | 诊断 → 崩溃数据 |
| 位置信息（GPX 轨迹） | ✅ | ✅ | 位置 → 精确位置（仅在导入 GPX 时收集） |
| 标识符 | ✅ | ✅ | 标识符 → 设备 ID（安装 ID） |
| 搜索历史 | ❌ | — | 不收集，不申报 |

### 1.3 用于"追踪"的说明（重要）

- 你的健康/身体数据**不上云的部分**仍要在"收集"里如实申报（苹果要求申报"App 访问了哪些数据"，无论是否上云）。
- 上传云端的去标识化 AI 摘要：仍与账号关联，归入"关联数据"。
- 不申报任何"追踪（Track）"项。

### 1.4 填写入口

App Store Connect → 你的 App → App 隐私 → 开始填写。填完后**必须点击"提交"并发布新版本才会生效**。

## 二、年龄分级（Age Rating）

> App Store Connect → 年龄分级。含 AI 生成内容建议至少 12+，如实填写。

| 问卷项 | 建议填写 | 依据 |
| --- | --- | --- |
| 是否含色情/性内容 | 否 | — |
| 是否含暴力/卡通暴力 | 否/轻微 | 训练场景，无暴力 |
| 是否含药物/酒精/烟草 | 否 | — |
| 是否含赌博 | 否 | — |
| 是否含未经筛选的互联网内容 | 否 | AI 内容经服务端校验与本地规则审核 |
| **是否含 AI 生成内容** | **是** | 有 AI Trainer/Motion/Recovery 生成内容 |
| 是否含医疗/健康相关内容 | 是 | 有身体数据、疼痛记录、康复建议 |
| 推荐年龄 | **12+**（因 AI 与健康内容） | — |

> 苹果 2025 起对 AI 生成内容 App 有额外要求（内容审核、举报机制、年龄限制），你的 App 已具备：AI 内容标识、确认制、举报渠道、本地安全规则优先。建议在审核备注中主动说明。

## 三、出口合规（Export Compliance）

> App Store Connect → App 信息 → 出口合规。你的 App 使用标准 HTTPS 与 Apple 加密库（CommonCrypto/SecKeychain 由系统提供），无自研密码学。

| 选项 | 建议 |
| --- | --- |
| 是否使用加密 | 是（HTTPS 传输） |
| 是否符合豁免 | 勾选"符合豁免条件"（标准商业加密、Apple 提供 API） |
| 说明 | 使用 TLS 传输与系统级 Keychain，无自研加密算法，符合 U.S. 出口豁免 |

## 四、审核备注（App Review Notes）建议

在提交审核时，填写以下备注可显著提高过审率：

> **审核备注（中文）**
> 1. 演示账号：请提供测试邮箱与验证码（或说明使用本地演示模式）。
> 2. 安全机制：本 App 的 AI 建议默认以待确认卡片展示，只有用户确认后才影响训练；本地规则引擎（疼痛 ≥7 强制休息/就医、康复约束、计划时间预算审计）始终优先于 AI 输出。
> 3. 健康数据边界：身体数据、HealthKit 原始样本默认仅保存在设备本地；仅在用户单独同意后，才发送去标识化训练摘要给 AI 服务。
> 4. 订阅：会员功能通过 App Store StoreKit 2 购买，服务端使用 Apple 服务端 API 校验凭证。
> 5. AI 内容：AI 生成内容均标注"AI 生成"，App 内提供举报渠道，7 个工作日内处理。
> 6. 附件：隐私政策 URL、服务条款 URL、健康免责声明。
